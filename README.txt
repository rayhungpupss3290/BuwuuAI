GitHub Pages 上傳方式：
1. 將 index.html 與整個 assets 資料夾一起上傳到 GitHub Repository 最外層。
2. Repository 結構應為：
   index.html
   assets/
     brand-philosophy.jpg
     services-space.jpg
     favicon.png
3. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save。
